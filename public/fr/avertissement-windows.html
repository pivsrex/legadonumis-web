Windows affiche-t-il un avertissement lors de l'installation de Legado ?

Oui, et c'est tout à fait normal. Voici quoi faire.

Ce que vous verrez

1

Lors du téléchargement, votre navigateur peut vous proposer de supprimer le fichier : choisissez de le conserver. Dans Chrome et Edge, l'option se trouve derrière les trois points, à côté de l'avertissement.

2

À l'ouverture, un écran bleu apparaîtra : « Windows a protégé votre ordinateur ». Cliquez sur « Informations complémentaires ».

3

Après avoir cliqué sur « Informations complémentaires », le bouton « Exécuter quand même » apparaîtra. Cliquez dessus pour continuer l'installation.

Pourquoi cet avertissement apparaît

Windows intègre une fonction de sécurité appelée SmartScreen. Lorsque vous téléchargez un programme, SmartScreen le compare à un registre de réputation géré par Microsoft : si le fichier est déjà connu et utilisé par de nombreuses personnes, il s'installe sans aucun message ; s'il est nouveau, ou n'a pas encore été vu sur de nombreux ordinateurs, il affiche cet écran bleu et vous demande de confirmer avant de continuer.

C'est une vérification de réputation, pas une analyse antivirus. SmartScreen ne dit pas qu'il a trouvé quelque chose de nuisible dans le fichier : il dit simplement que le fichier ne lui est pas encore familier. Pour la même raison, votre navigateur peut vous avertir que le programme d'installation de Legado n'est pas couramment téléchargé.
