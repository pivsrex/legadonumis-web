Welche Daten erhoben werden und wozu

Diese Website und die Anwendung Legado folgen einer schlichten Datenpolitik:

  • E-Mail-Adresse (direkter Kontakt): wenn Sie uns direkt schreiben, verwenden wir Ihre Adresse ausschließlich, um Ihnen zu antworten. Sie wird in keinem externen System gespeichert und zu keinem anderen Zweck genutzt.
  • E-Mail-Adresse (Neuigkeiten-Liste): wenn Sie die Neuigkeiten von Legado freiwillig über das Formular dieser Website abonnieren, wird Ihre Adresse bei Loops (loops.so) gespeichert, dem Dienst, mit dem wir diese Liste verwalten. Ihre Einwilligung ist ausdrücklich, freiwillig und unabhängig vom Download der Anwendung. Sie können sich jederzeit abmelden, über den Abmeldelink in jeder E-Mail oder indem Sie schreiben an contacto@legadonumis.com. Loops handelt als Auftragsverarbeiter; bitte lesen Sie dessen Datenschutzerklärung auf loops.so.
  • Zahlungsdaten: werden vollständig von LemonSqueezy, unserem Zahlungsdienstleister, verarbeitet. Legado speichert Ihre Karten- oder Bankdaten nicht und hat keinen Zugriff darauf. Bitte lesen Sie die Datenschutzerklärung von LemonSqueezy auf lemonsqueezy.com.
  • Daten der Sammlung: Legado speichert Ihre Sammlung in einer lokalen Datei auf Ihrem Rechner. Legado hat keine eigenen Server und sendet Ihre Daten an keinen Server, den wir kontrollieren. Wenn Sie diese Datei in einem mit der Cloud synchronisierten Ordner ablegen (iCloud, Dropbox, Google Drive usw.), erfolgt diese Synchronisierung eigenständig durch jene Dienste und unterliegt deren eigenen Datenschutzerklärungen.

Cookies und Reichweitenmessung

Diese Website verwendet weder Tracking-Cookies noch Analysewerkzeuge. Ihr Surfverhalten wird nicht nachverfolgt, und es werden keine Informationen zu Werbezwecken an Dritte weitergegeben.

KI-Assistent

Legado Pro enthält einen integrierten Dienst zur Inhaltserzeugung mit künstlicher Intelligenz, der auf der API von Anthropic (Claude) beruht. Wenn Sie diese Funktion nutzen, wird der von Ihnen übermittelte Text (Beschreibung der Münze oder Banknote oder weitere Felder, die Sie freigeben) über den Proxy von legadonumis.com an die Server von Anthropic übertragen. Legado speichert diese Anfragen nicht. Anthropic verarbeitet sie nach seiner eigenen Datenschutzerklärung, einsehbar auf anthropic.com.

Ihre Rechte

Sie können jederzeit Auskunft über, Berichtigung oder Löschung der bei uns vorliegenden personenbezogenen Daten verlangen, indem Sie schreiben an contacto@legadonumis.com. Wir antworten innerhalb von 30 Tagen.
