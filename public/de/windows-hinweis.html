Zeigt Windows beim Installieren von Legado eine Warnung?

Ja, und das ist kein Problem. Hier erfahren Sie, was zu tun ist.

Was Sie sehen werden

1

Beim Herunterladen kann Ihr Browser anbieten, die Datei zu verwerfen: wählen Sie stattdessen „Behalten". In Chrome und Edge finden Sie diese Option hinter den drei Punkten neben der Warnmeldung.

Screenshot in Kürze verfügbar
2

Beim Öffnen erscheint ein blauer Bildschirm: „Windows hat Ihren PC geschützt". Klicken Sie auf „Weitere Informationen".

Screenshot in Kürze verfügbar
3

Nach dem Klick auf „Weitere Informationen" erscheint der Schaltfläche „Trotzdem ausführen". Klicken Sie darauf, um die Installation fortzusetzen.

Screenshot in Kürze verfügbar

Warum diese Warnung erscheint

Legado ist im Apple Developer Program registriert, weshalb die macOS-Version ohne jede Warnung installiert wird. Unter Windows ist das Äquivalent ein Code-Signatur-Zertifikat, das Legado noch nicht besitzt. Deshalb zeigt Windows diese Warnung. Das Programm ist auf beiden Plattformen exakt dasselbe.

Laden Sie immer von legadonumis.com herunter

Dies ist die einzige offizielle Quelle. Wenn Sie das Installationsprogramm von legadonumis.com heruntergeladen haben, können Sie es bedenkenlos installieren.
