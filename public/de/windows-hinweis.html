Zeigt Windows beim Installieren von Legado eine Warnung?

Ja, und das ist kein Problem. Hier erfahren Sie, was zu tun ist.

Was Sie sehen werden

1

Beim Herunterladen kann Ihr Browser anbieten, die Datei zu verwerfen: wählen Sie stattdessen „Behalten". In Chrome und Edge finden Sie diese Option hinter den drei Punkten neben der Warnmeldung.

2

Beim Öffnen erscheint ein blauer Bildschirm: „Windows hat Ihren PC geschützt". Klicken Sie auf „Weitere Informationen".

3

Nach dem Klick auf „Weitere Informationen" erscheint die Schaltfläche „Trotzdem ausführen". Klicken Sie darauf, um die Installation fortzusetzen.

Warum diese Warnung erscheint

Windows enthält eine Sicherheitsfunktion namens SmartScreen. Wenn Sie ein Programm herunterladen, vergleicht SmartScreen es mit einer Reputationsdatenbank, die Microsoft pflegt: Ist die Datei bereits bekannt und wird von vielen Menschen genutzt, wird sie ohne Hinweis installiert; ist sie neu oder wurde sie noch nicht auf vielen Computern gesehen, zeigt Windows diesen blauen Bildschirm und bittet Sie, vor dem Fortfahren zu bestätigen.

Es ist eine Reputationsprüfung, kein Virenscan. SmartScreen sagt nicht, dass es etwas Schädliches in der Datei gefunden hat: Es sagt lediglich, dass die Datei ihm noch nicht vertraut ist. Aus demselben Grund kann Ihr Browser Sie darauf hinweisen, dass das Legado-Installationsprogramm nicht häufig heruntergeladen wird.
